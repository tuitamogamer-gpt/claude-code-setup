# firecrawl-deep-research

Produce an intensive, cited analytical report: executive summary, multi-angle findings, contrarian views, open questions, and full sources. Use only when the user needs rigorous synthesis of a complex topic (scientific, technical, policy, or market-analytical) that cannot be answered with a short search, and wants a formal written report, not a recommendation list. ## Install

Copy this folder to `~/.claude/skills/firecrawl-deep-research/` (or run `install.sh`). Requires the Firecrawl MCP server + `FIRECRAWL_API_KEY` (see `../../mcp-servers/firecrawl/`).
