# firecrawl-parse

Efficiently extract and convert the contents of any local file—such as PDF, DOCX, DOC, ODT, RTF, XLSX, XLS, or HTML—into clean, well-formatted markdown saved to disk. Use this skill whenever the user requests to parse, read, or extract information from a file on their computer, including phrases like “parse this PDF”, “convert this document”, “read this file”, “extract text from”, or when a local file path (not a URL) is provided. ## Install

Copy this folder to `~/.claude/skills/firecrawl-parse/` (or run `install.sh`). Requires the Firecrawl MCP server + `FIRECRAWL_API_KEY` (see `../../mcp-servers/firecrawl/`).
