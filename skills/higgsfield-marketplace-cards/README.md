# higgsfield-marketplace-cards

Generate marketplace product image cards through Higgsfield: compliant main image, secondary product images, and A+ style content modules. Use when the user asks for marketplace listing images, product detail cards, secondary product images, product infographics, lifestyle listing shots, A+ style content, marketplace image sets, or sales-ready product visuals. Backend owns marketplace compliance references and prompt templates; this skill only routes user intent to the CLI. NOT for generic…

## Install

Copy this folder to `~/.claude/skills/higgsfield-marketplace-cards/` on the target machine (or run `install.sh` from the repo root). Trigger inside Claude Code with `/higgsfield-marketplace-cards`.
