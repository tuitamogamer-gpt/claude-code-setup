# YouTube Škola Plugin

Sveobuhvatan plugin za kompletni YouTube proces - od strategije kanala do monetizacije. Baziran na metodologiji YouTube Škole sa 12 lekcija praktičnog znanja.

## Komponente

### Skills (7)

| Skill | Opis |
|-------|------|
| **youtube-algoritam** | CCN model publike, AVPV metrika, tematska fokusiranost, algoritamske faze |
| **tnt-pakovanje** | ORA framework za thumbnailove i naslove, CTR optimizacija |
| **skripta-i-storytelling** | Hook, uvod, open loops, cliffhanger, struktura skripte |
| **youtube-monetizacija** | Digitalni proizvodi, funnel, newsletter, CTA strategija |
| **analiza-kanala** | Sistematska revizija kanala po 6 oblasti |
| **video-produkcija** | Editing principi, format, face vs faceless, redovnost |
| **content-planiranje** | Odabir niše, mini serijali, content kalendar, lansiranje |

### Komande (7)

| Komanda | Opis |
|---------|------|
| `/yt-naslov` | Generiši naslov koristeći ORA framework |
| `/yt-thumbnail` | Kreiraj koncept thumbnailova |
| `/yt-skripta` | Napiši kompletnu video skriptu |
| `/yt-analiza` | Analiziraj YouTube kanal |
| `/yt-plan` | Kreiraj content plan i kalendar |
| `/yt-tnt-review` | Revizija naslova i thumbnailа |

| `/yt-opis` | Napiši opis za YouTube video |

## Ključni Frameworkovi

### ORA (Obećanje, Radoznalost, Autentičnost)
Za thumbnail i title. Obećanje je najbitnije, radoznalost drugo, autoritet treće.

### CCN (Core, Casual, New)
Model publike. Algoritam prvo prikaže Core, pa Casual, pa New. Video mora zadovoljiti sva tri nivoa.

### AVPV (Average Videos Per View)
Najbitnija algoritamska metrika. Koliko videa gledalac pogleda nakon jednog. Cilj: bindžanje.

### TNT (Title & Thumbnail)
Pravi se PRIJE videa. Prvo TNT, pa onda skripta, pa snimanje.

## Korištenje

Skill-ovi se automatski aktiviraju kada postavljate pitanja vezana za YouTube. Komande se pokreću sa `/yt-` prefiksom.

Primjeri:
- "Kako da poboljšam svoj YouTube kanal?" → aktivira analiza-kanala skill
- "Napiši mi naslov za video o kuhanju" → aktivira tnt-pakovanje skill
- `/yt-skripta kako napraviti savršen espresso` → pokreće skriptu
- `/yt-plan programiranje za početnike` → kreira content plan
