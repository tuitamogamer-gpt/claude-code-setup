# cowork-plugin-management

Create, customize, and manage plugins tailored to your organization's tools and workflows. Configure MCP servers, adjust plugin behavior, and adapt templates to match how your team works.

## Install

This is a Claude Desktop (Cowork) plugin. It is normally provisioned by your claude.ai account — log in with the same account on the new machine and it appears automatically. This copy is a backup; custom plugins can be re-imported via the Cowork plugin manager, or their `skills/`+`commands/` folders copied into `~/.claude/`.
