# pragmatic-technical-writing

Create technical content in the author's "bez iluzija" (without illusions) style — personal narrative, honest assessment, and practical guidance that challenges both hype and complacency. Use for technical books and e-books, blog posts, newsletters, YouTube scripts, thought-leadership articles, and educational content about AI and technology. Trigger whenever the user asks to write "u mom stilu", "bez iluzija", "za AI bez iluzija", "blog post o...", "newsletter", "tekst za moju publiku", or any…

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/pragmatic-technical-writing/`.
