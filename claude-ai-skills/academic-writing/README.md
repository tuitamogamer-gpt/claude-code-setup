# academic-writing

Academic paper writing following the author's structured, pragmatic approach. Use when creating research papers, journal articles, conference submissions, or academic analyses. Emphasizes clear research questions, systematic methodology sections, balanced discussion of capabilities and limitations, transparent AI tool disclosure, and APA citation style. Applies the "bez iluzija" (without illusions) philosophy—honest assessment without hype or unwarranted pessimism.

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/academic-writing/`.
