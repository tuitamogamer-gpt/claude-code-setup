# Citation Guide (APA 7th Edition)

## In-Text Citations

### Single Author
```
(Smith, 2023)
Smith (2023) argues that...
```

### Two Authors
```
(Smith & Jones, 2023)
Smith and Jones (2023) demonstrate...
```

### Three or More Authors
```
(Smith et al., 2023)
Smith et al. (2023) found...
```

### Direct Quote
```
"quoted text" (Smith, 2023, p. 45)
```

### Multiple Sources
```
(Jones, 2022; Smith, 2023; Williams et al., 2021)
```

## Reference List Formats

### Journal Article
```
Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, 
Volume(Issue), Page–Page. https://doi.org/xxxxx
```

Example:
```
Summerville, A., Snodgrass, S., Guzdial, M., & Togelius, J. (2018). 
Procedural content generation via machine learning. IEEE Transactions 
on Games, 10(3), 257–270. https://doi.org/10.1109/TG.2018.2846639
```

### Book
```
Author, A. A. (Year). Title of work: Capital letter also for subtitle. 
Publisher.
```

Example:
```
Yannakakis, G. N., & Togelius, J. (2018). Artificial intelligence and 
games. Springer.
```

### Book Chapter
```
Author, A. A. (Year). Title of chapter. In E. E. Editor (Ed.), Title of 
book (pp. xx–xx). Publisher.
```

Example:
```
Jenkins, H. (2004). Game design as narrative architecture. In N. Wardrip-Fruin 
& P. Harrigan (Eds.), First person: New media as story, performance, and 
game (pp. 118–130). MIT Press.
```

### Conference Paper
```
Author, A. A. (Year, Month Day–Day). Title of paper. Conference Name, 
Location. https://doi.org/xxxxx
```

Example:
```
Kumaran, V., Rowe, J., Mott, B. W., & Lester, J. (2023, August). SceneCraft: 
Automating interactive narrative scene generation. Proceedings of the AAAI 
Conference on Artificial Intelligence and Interactive Digital Entertainment, 
Salt Lake City, UT.
```

### Preprint/ArXiv
```
Author, A. A. (Year). Title of paper. arXiv preprint arXiv:XXXX.XXXXX
```

Example:
```
Zhang, J., Zhang, J., & Huang, S. (2022). A survey on procedural content 
generation: From handcrafted to learning-based methods. arXiv preprint 
arXiv:2207.10466.
```

### Website/Online Source
```
Author/Organization. (Year, Month Day). Title of page. Site Name. URL
```

Example:
```
Argentics. (2024). AI tools for game development. 
https://www.argentics.io/ai-tools-for-game-development
```

### News Article
```
Author, A. A. (Year, Month Day). Title of article. Publication Name. URL
```

Example:
```
Livingston, C. (2023, April 28). Modder wires ChatGPT into Skyrim VR, 
allowing NPCs to roleplay. PC Gamer. https://www.pcgamer.com/...
```

### Wiki/Reference Source
```
Source Name. (n.d.). Article title. Retrieved Month Day, Year, from URL
```

Example:
```
UESP. (n.d.). Skyrim:NPCs. https://en.uesp.net/wiki/Skyrim:NPCs
```

## Integration Patterns

### Introducing Sources
```
As [Author] ([Year]) observes, "[brief quote]" (p. X).
[Author] ([Year]) demonstrates that [paraphrase].
According to [Author] ([Year]), [claim].
Research by [Author] et al. ([Year]) indicates [finding].
```

### Synthesizing Multiple Sources
```
Several studies have examined [topic] ([Author1], [Year]; [Author2], [Year]).
The evolution of [field] can be categorized into [stages] ([Author], [Year]).
This aligns with [Author's] ([Year]) framework for [concept].
```

### Acknowledging Limitations
```
As [Author] ([Year]) notes, [limitation].
While [Author] ([Year]) provides [contribution], [gap remains].
```

## Reference List Organization

- Alphabetize by first author's surname
- Hanging indent (0.5 inch) for entries longer than one line
- Double-space between entries
- Include DOIs when available
- Use "https://" format for URLs (no "Retrieved from" unless date-specific)
