# aistudio-transcribe

Transcribe YouTube videos using Google AI Studio (Gemini) via browser automation. Use this skill whenever the user wants to: transcribe a video, get text with timestamps from a YouTube video, convert video speech to text, create subtitles or captions from a video, or analyze video content for quotes/excerpts. Also triggers on: "transkribuj video", "napravi transkripciju", "izvuci tekst iz videa", "timestampovi", "pretvorite govor u tekst", or any request that involves a YouTube URL and…

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/aistudio-transcribe/`.
