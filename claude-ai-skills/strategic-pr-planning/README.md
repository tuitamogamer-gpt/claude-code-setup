# strategic-pr-planning

Comprehensive strategic planning for public relations and organizational communication. Use when creating PR plans, communication strategies, or organizational positioning for non-profits, educational institutions, student organizations, NGOs, or similar entities. Covers environmental analysis, stakeholder identification, image management, strategic goal setting, internal/external communication, media relations, crisis management, and operational planning with measurable outcomes.

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/strategic-pr-planning/`.
