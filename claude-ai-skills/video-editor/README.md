# video-editor

Professional video editing with FFmpeg. Use when the user wants to edit video files (.mp4, .mov, .mkv, .avi, .webm) including removing silences/pauses, trimming, adding zoom effects, enhancing audio, cutting segments, concatenating clips, adjusting speed, or any video manipulation task. Triggers on keywords like "edit video", "remove pauses", "cut silences", "trim video", "enhance audio", "add zooms", "speed up video", "compress video".

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/video-editor/`.
