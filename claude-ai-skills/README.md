# Claude.ai — Account Skills (25)

Skillovi koji žive u claude.ai nalogu (Settings → Capabilities → Skills) i automatski prate
nalog na svakom uređaju — **nije ih potrebno ručno instalirati** na novom računaru.

Ovaj folder je **backup kopija** (izvučena iz lokalnog mirror-a Desktop aplikacije). Koristi se:

1. Ako neki skill nestane sa naloga — ovde je kopija za ponovni upload.
2. Za korišćenje u Claude Code CLI-ju bez naloga: iskopiraj folder u `~/.claude/skills/<ime>/`.

Custom skillovi vredni čuvanja: `seedance-prompt-structure`, `workbook-pdf-design`,
`gdrive-jarvis`, `aistudio-transcribe`.
