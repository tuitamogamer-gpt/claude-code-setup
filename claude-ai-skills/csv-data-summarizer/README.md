# csv-data-summarizer

- Analyzes CSV files end-to-end — summary statistics, data quality checks, and automatic visualizations using Python and pandas. Use this skill whenever the user uploads or references a CSV/TSV file and wants to understand it — "summarize this data", "analyze this CSV", "what's in this file", "show me trends", "any insights here" — or even just uploads a CSV with a vague ask. Runs the full analysis immediately without asking what the user wants first.

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/csv-data-summarizer/`.
