# catan-player

Play Catan Universe (Steam) via computer-use — screen reading, mouse clicks, and keyboard shortcuts. Use this skill whenever the user asks you to play Catan, make moves in Catan Universe, help with a Catan game in progress, or automate Catan gameplay. Triggers on "play Catan", "Catan Universe", "my turn in Catan", "Catan move", "settle in Catan", or any request involving the Catan Universe digital board game.

## Install

This skill lives in your claude.ai account (Settings → Capabilities → Skills) and follows the account automatically. This copy is a backup; it can also be used in the CLI by copying the folder to `~/.claude/skills/catan-player/`.
